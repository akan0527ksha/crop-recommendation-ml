# crop-recommendation-ml
AI-based Crop Recommendation System using XGBoost and Gradio
This project predicts the most suitable crop to grow based on soil nutrients and environmental conditions using XGBoost Machine Learning Model and a simple Gradio Web Interface.

🔍 Features

Accurate crop prediction using XGBoost

Seven input parameters (N, P, K, Temperature, Humidity, pH, Rainfall)

User-friendly Gradio interface

Hosted on Google Colab

ML pipeline with scaling & label encoding

🧠 Machine Learning Model

XGBoost Classifier

StandardScaler

Label Encoding

Train-test split

Accuracy printed during training

🚀 Technologies Used

Python

Pandas

Scikit-learn

XGBoost

Gradio
